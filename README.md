# README.md

# MiMo Web Toolkit

## MCP Toolkit для Xiaomi MiMo Code с локальной генерацией изображений

Версия: 1.0

---

# Описание проекта

**MiMo Web Toolkit** — это локальный MCP Toolkit, расширяющий возможности Xiaomi MiMo Code.

Проект позволяет MiMo Code автоматически использовать инструменты генерации и обработки изображений при разработке веб-сайтов.

Основной сценарий:

Пользователь описывает веб-проект.

MiMo самостоятельно:

* анализирует необходимость изображений;
* вызывает MCP Tool;
* генерирует изображения через ComfyUI;
* оптимизирует их;
* интегрирует в проект.

---

Поддерживаются:

Планируется:

---

## Оптимизация

Поддержка:

* WebP;
* PNG;
* JPG;
* AVIF.

# Установка

## 1. Клонирование проекта

```bash
git clone https://github.com/example/mimo-web-toolkit.git

cd mimo-web-toolkit
```

---

## 2. Создание окружения Python

```bash
python -m venv venv
```

Активация:

Windows:

```bash
venv\Scripts\activate
```

---

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

# Настройка ComfyUI

Необходимо:

1. установить ComfyUI;
2. установить FLUX.1 Schnell;
3. запустить ComfyUI API;
4. указать параметры подключения в:

```
config/settings.yaml
```

---

# Запуск MCP Server

Команда:

```bash
python -m mcp_server.server
```

После запуска сервер становится доступен MiMo Code.

---

# Подключение MiMo Code

MiMo Code должен быть настроен на использование MCP Server проекта.

После подключения доступны инструменты:

```
generate_image
generate_logo
generate_icons
optimize_image
...
```

---

# Первый пример

Запрос к MiMo:

```
Создай лендинг современной кофейни.
Используй изображения и логотип.
```

MiMo должна:

1. создать структуру сайта;
2. вызвать генерацию изображений;
3. получить файлы;
4. вставить их в проект.

# Структура проекта

```
mimo-web-toolkit/

├── config/
├── workflows/
├── assets/
├── cache/
├── mcp_server/
```

Основные каталоги:

- mcp_server — MCP сервер и инструменты

- assets — изображения

- tests — тесты
- scripts — вспомогательные скрипты
