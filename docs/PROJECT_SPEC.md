# PROJECT_SPEC.md

# MiMo Web Toolkit

**Версия:** 1.0

---

# Назначение проекта

Создать полноценный open-source toolkit для Xiaomi MiMo Code, позволяющий модели самостоятельно генерировать изображения при разработке сайтов.

Проект должен использовать локальную генерацию изображений через ComfyUI и FLUX.1 Schnell и взаимодействовать с MiMo Code посредством MCP (Model Context Protocol).

Главная цель проекта — предоставить MiMo Code набор интеллектуальных инструментов, позволяющих автоматически создавать, оптимизировать и использовать изображения в процессе разработки веб-сайтов.

---

# Целевая платформа

Операционная система:

* Windows 10

Аппаратная конфигурация:

* NVIDIA RTX 3080
* 10 GB VRAM
* 32 GB RAM

Среда:

* Python 3.11
* официальный CLI Xiaomi MiMo Code
* локальный ComfyUI
* FLUX.1 Schnell

Ограничения:

* генерация должна быть оптимизирована под GPU с 10 GB VRAM;
* необходимо поддерживать CPU/RAM offloading;
* нельзя рассчитывать на наличие GPU с большим объёмом памяти;
* workflow должны учитывать ограничение VRAM.
* Облачные сервисы использовать нельзя.
* Проект должен работать полностью локально.

---

# Конечная цель

После завершения проекта пользователь должен иметь возможность написать MiMo Code:

> Создай современный лендинг стоматологической клиники.

После этого MiMo должна самостоятельно:

1. создать структуру проекта;
2. написать HTML;
3. написать CSS;
4. написать JavaScript;
5. определить необходимость генерации изображений;
6. вызвать MCP Tool;
7. получить изображения;
8. сохранить изображения в assets;
9. вставить изображения в HTML;
10. прописать alt-теги;
11. оптимизировать изображения.

Всё должно происходить автоматически.

# Генерация изображений

Запрещается использовать интерфейс:

```python
generate_image(prompt)
```

Нужно реализовать высокоуровневый интерфейс.

Например:

```python
generate_image(
    purpose="hero",
    subject="Luxury Hotel",
    filename="hero.webp",
    style="photorealistic",
    aspect_ratio="16:9"
)
```

Функция самостоятельно должна:

* выбрать prompt template;
* выбрать workflow;
* определить разрешение;
* подобрать sampler;
* подобрать scheduler;
* подобрать CFG;
* подобрать Steps;
* сформировать negative prompt;
* сохранить результат в WebP;
* вернуть путь к изображению.
