# ROADMAP.md

# MiMo Web Toolkit

## План разработки

Версия: 1.0

---

# Основная цель

Построить промышлененный open-source MCP Toolkit для Xiaomi MiMo Code, позволяющий автоматически использовать локальную генерацию изображений через ComfyUI при разработке веб-сайтов.

Каждый этап должен завершаться полностью рабочим состоянием проекта.

Никогда не переходить к следующему этапу, пока предыдущий не завершён полностью.

---

# Правила разработки

Перед каждым этапом необходимо:

1. объяснить архитектурное решение;
2. показать дерево файлов;
3. полностью написать новые файлы;
4. объяснить принятые решения.

После каждого этапа необходимо:

* перечислить созданные файлы;
* перечислить изменённые файлы;
* показать следующий этап.

Если обнаружено более удачное архитектурное решение:

* объяснить преимущества;
* предложить изменение;
* только после согласования изменить архитектуру.

# Формат взаимодействия

Во время разработки MiMo должна выступать в роли ведущего разработчика.

Каждый ответ должен содержать:

1. краткое описание этапа;
2. архитектурное решение;
3. дерево файлов;
4. полный код всех новых файлов;
5. пояснение кода;
6. результаты этапа;
7. следующий этап.

Все файлы должны быть полностью готовы к сохранению и запуску.
