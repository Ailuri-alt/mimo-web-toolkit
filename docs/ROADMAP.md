# ROADMAP.md

# MiMo Web Toolkit

## План разработки

Версия: 1.0

---

# Основная цель

Построить промышлененный open-source MCP Toolkit для Xiaomi MiMo Code, позволяющий автоматически использовать локальную генерацию изображений через ComfyUI при разработке веб-сайтов.

Каждый этап должен завершаться полностью рабочим состоянием проекта.

Никогда не переходить к следующему этапу, пока предыдущий не завершён полностью.

---

# Правила разработки

Перед каждым этапом необходимо:

1. объяснить архитектурное решение;
2. показать дерево файлов;
3. полностью написать новые файлы;
4. объяснить принятые решения.

После каждого этапа необходимо:

* перечислить созданные файлы;
* перечислить изменённые файлы;
* показать следующий этап.

Если обнаружено более удачное архитектурное решение:

* объяснить преимущества;
* предложить изменение;
* только после согласования изменить архитектуру.

# Этап 6

## Provider Layer

Создать слой провайдеров моделей генерации изображений.

Реализовать:

* base.py — базовый интерфейс ImageProvider;
* flux_provider.py — провайдер для FLUX.1 Schnell/Dev;
* provider_registry.py — реестр провайдеров.

Правило: Provider никогда не выполняет HTTP-запросы к ComfyUI.

Вся коммуникация через comfy_client.py.

# Этап 19A

## Workflow JSON + Тесты

Восполнение инфраструктуры для Этапов 1-19.

### Workflow JSON

Создать JSON-файлы в `workflows/flux/` для каждого purpose:

* hero.json
* logo.json
* icons.json
* background.json
* team_photo.json
* product.json

### Тесты

Базовые pytest-тесты для:

* `mcp_server/services/image_processor.py` (process, resize, get_info)
* `mcp_server/services/prompt_engine.py` (build_prompt)
* `mcp_server/services/workflow_engine.py` (get_workflow_path, get_generation_params)
* `mcp_server/services/comfy/comfy_client.py` (mock-based)
* `mcp_server/tools/` (handler для каждого tool)
