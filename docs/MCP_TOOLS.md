# MCP_TOOLS.md

# MCP Tools Specification

## MiMo Web Toolkit

Версия: 1.0

---

# Назначение

Этот документ описывает MCP-инструменты, предоставляемые проектом **MiMo Web Toolkit** для Xiaomi MiMo Code.

Документ является контрактом между:

* MiMo Code;
* MCP Server;
* внутренними компонентами Toolkit.

Любое изменение публичного интерфейса MCP Tool должно быть отражено в этом документе.

---

# Общие принципы MCP Tools

Все инструменты должны:

* иметь понятное назначение;
* принимать структурированные параметры;
* возвращать структурированный результат;
* корректно обрабатывать ошибки;
* логировать выполнение;
* не зависеть от конкретной модели генерации.

---

# Общий формат ответа

Все инструменты должны возвращать объект следующего вида:

```json
{
  "success": true,
  "result": {},
  "error": null
}
```

При ошибке:

```json
{
  "success": false,
  "result": null,
  "error": {
    "type": "ImageGenerationError",
    "message": "Description"
  }
}
```

---

# 1. generate_image

## Назначение

Универсальный инструмент генерации изображений.

Используется, когда MiMo требуется создать изображение общего назначения.

---

## Когда использовать

Примеры:

* Hero Banner;
* иллюстрация;
* изображение для секции сайта;
* декоративное изображение.

---

## Входные параметры

```json
{
  "purpose": "hero",
  "subject": "Luxury hotel",
  "filename": "hero.webp",
  "style": "photorealistic",
  "aspect_ratio": "16:9"
}
```

---

## Параметры

### purpose

Тип изображения.

Допустимые значения:

```
hero
background
illustration
product
portrait
custom
```

---

### subject

Описание объекта изображения.

Пример:

```
modern luxury hotel lobby
```

---

### filename

Имя итогового файла.

Пример:

```
hero.webp
```

---

### style

Стиль изображения.

Пример:

```
photorealistic
cinematic
minimal
3d
illustration
```

---

### aspect_ratio

Соотношение сторон.

Пример:

```
16:9
1:1
4:3
9:16
```

---

## Возвращаемый результат

```json
{
  "success": true,
  "file": "assets/hero/hero.webp"
}
```

# 5. generate_team_photo

## Назначение

Создание изображений людей и команд.

---

* корректное описание персонажей.

# Версионирование MCP Tools

При изменении интерфейса инструмента необходимо:

1. обновить этот документ;
2. сохранить обратную совместимость;
3. увеличить версию API.

---

# Расширение инструментов

Добавление нового MCP Tool должно включать:

* описание назначения;
* описание параметров;
* пример использования;
* описание ошибок;
* обновление данного документа.

---

# Цель

Создать понятный и стабильный интерфейс, позволяющий Xiaomi MiMo Code использовать возможности локальной генерации и обработки изображений как встроенные инструменты разработки.
