# MiMo Web Toolkit — Project Initialization Prompt

Ты являешься главным AI-архитектором проекта **MiMo Web Toolkit**.

Твоя задача — провести полный аудит проектной документации, привести её к единому состоянию и подготовить проект к началу разработки.

---

# Контекст проекта

Проект:

**MiMo Web Toolkit**

Цель:

Создать локальный MCP Toolkit, позволяющий AI-агентам:

* Xiaomi MiMo Code;
* Claude Code;
* другим MCP-клиентам

использовать локальную генерацию и обработку изображений при разработке веб-приложений.

---

# Аппаратная платформа

Целевая система:

* Windows 10
* NVIDIA RTX 3080
* 10 GB VRAM
* 32 GB RAM

Ограничения:

* необходимо учитывать ограниченный VRAM;
* поддерживать offload в RAM;
* использовать очередь генерации;
* избегать параллельных тяжёлых задач.

# Главная задача

Проведи архитектурный аудит проекта.

Не начинай написание кода.

Сначала необходимо привести документацию к единому состоянию.

---

# Этап 1. Анализ документации

Проверь:

1. Нет ли противоречий между документами.
2. Совпадает ли структура проекта.
3. Совпадают ли названия компонентов.
4. Соответствует ли архитектура требованиям.
5. Не потерялись ли важные решения.

Создай отчет:

```
docs/DOCUMENTATION_AUDIT.md
```

В отчете укажи:

* найденные проблемы;
* важность проблемы;
* предлагаемый вариант исправления.

---

# Этап 2. Проверка архитектуры

Особое внимание удели:

## Model Provider Layer

Проверь наличие архитектурного слоя:

```
mcp_server/

services/

providers/

base.py
flux_provider.py
sdxl_provider.py
registry.py
```

Проверь:

* возможность замены моделей;
* поддержку FLUX.1 Schnell;
* поддержку FLUX.1 Dev NF4/GGUF;
* возможность добавления новых моделей.

---

# Этап 3. Проверка MCP архитектуры

Проверь соответствие:

```
AI Client

    |

    |

    |

    |
```

# Этап 4. Проверка ComfyUI интеграции

Проверь:

* описан ли API режим;
* описана ли работа с workflow;
* учитываются ли ограничения RTX 3080.

# Этап 6. Подготовка структуры проекта

# Этап 7. Только после аудита

Когда документация согласована:

подготовь план реализации:

```
IMPLEMENTATION_PLAN.md
```

План должен включать:

1. создание структуры каталогов;
2. создание Python окружения;
3. настройку ComfyUI;
4. создание MCP Server;
5. создание первого Tool;
6. подключение MiMo Code;
7. первый тест генерации изображения.

3. внеси изменение только после согласования.
